⚙️ ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ (FULLSTACK)

- Frontend: Next.js 15 (App Router) + Tailwind CSS + GSAP. Адаптивная вёрстка (mobile-first).
- Backend: Next.js API Routes.
- База данных: Supabase (через твой Supabase MCP). Таблицы:
  - products (id, name, slug, composition, price, image_url, category, in_stock)
  - stones (id, name, slug, description, history, image_url)
  - orders (id, customer_name, customer_email, customer_phone, address, total, status, created_at, items — JSON поле для списка товаров)
  - custom_orders (id, stones_selected, base_price, total_price, status, customer_data, created_at)
- Корзина: хранить в localStorage, при оформлении отправлять на бэкенд, который создаёт запись в таблице orders.
- Оплата: интеграция с ЮKassa (создание платежа через API, обработка уведомлений). Для MVP можно реализовать режим тестирования с кнопкой «Оплатить» без реального списания, но с полной документацией по подключению ЮKassa.
- Админка: защищённая паролем (простой middleware или базовая HTTP-аутентификация). Возможности:
  - Просмотр и редактирование списка товаров.
  - Просмотр заказов (обычных и кастомных), изменение статуса.
  - Добавление/редактирование информации о камнях.
  - Просмотр и модерация отзывов (для будущего функционала).
- Фото: использовать локальные файлы из папок stones и bracelets по именам, соответствующим названиям камней и браслетов (латиница или транслит). Для MVP, если файлов нет — генерировать заглушки с помощью Unsplash API или подставлять placeholder.
